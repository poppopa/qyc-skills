# 课程到学习计划的映射

## 1. 先锁定学习对象

完整读取之后，将页面描述转成“原课程证据摘要”，不先按主题知识自行编课：

- 课程核心问题与目标成果。
- 实际公布的模块、原题编号与原题标题。
- 原案例、项目/代码说明与前置基础。
- 讲师主张与课程承诺（只是页面描述，不当作独立性能证据）。
- 当前发布状态、全文/试读访问范围、尚未确定项。

示例里的“ProdAgent”“售后退款助手”等只能用于确实读取到的那门课，不硬编码为所有极客时间课的贯穿项目。新课程重新提取，不沿用旧课程目录。

## 2. 课程原骨架与教练分层

明确两条结构并保留联系：

- **原课结构**：极客时间实际公布的模块与各讲，是覆盖范围与出处。
- **教练结构**：L1全貌、L2小时级主线、L3+后续深化，是用户这次选择的学习方式；不冒称讲师原分层。

首次给链接或只要计划时：

1. 提供课程定位与约1～5分钟全貌；若用户明确跳过概览则照做。
2. 给不排时的全课程路线草案，保留原模块和关键依赖，说明哪些可选/后续。
3. 只问决定有预算计划的必要项，优先本轮目标与小时预算；基础已知就不重复问。用户已给齐条件就直接规划。
4. “推荐2小时”只能是建议，不变成已确认计划；用户明确让你决定时才采用教练默认并写明假设。不要默认每周学习数天或总共数周。

小时预算过短时，主线可以只覆盖部分，但全课程其余内容必须列去向：下一轮主线、L3深化、选学或明确暂缓。不能把2小时压缩课冒称等价于完成38讲原课程。

## 3. 建立可追溯映射

每个教练小节在内部或输出中保存以下信息（可用逐节列表，不强制表格）：

- 小节短标题、一个核心问题、可观察成果。
- 原模块、对应原题编号+原题标题，来源URL。
- 教练拆合与重排理由：内容依赖、目标选择或时间限制。
- 主线/选学/后续/暂缓，以及是否未发布。
- 前置小节/知识、讲解分钟、理解/练习分钟、回顾分钟。
- 练习与验收，以及它们是教练设计还是原课实际提供。

按原顺序为默认，不强制每原讲恰好一教练节。强相关可合并，重难点可拆分；拆合不能改变原题意思或丢关键能力。无法确认逐讲题名时只到已验证模块层级映射。

覆盖检查：每个原模块以及已读出的原题应至少出现一次去向；一个原题映射多节时不重复算原讲数。课程总数和教练小节数分别展示。

## 4. 预算与能力边界

- 沿用教练当前版本的节数/时长规则。一般L2约4～8节，每节围绕一个问题，按实际基础和预算调整，不为整齐硬套。
- 总和：讲解 + 理解/轻练习 + 回顾 <= 已确认本轮分钟。先用明确分钟核对再交付，不能用“约2小时”遮掩超支。
- 原课观看/阅读、外部资料、环境搭建、大型项目、调试与实地练习单独估时；无证据的原课时长标未知，不按讲数假造时长。
- 用“能解释状态恢复的前提/能判断一个并发例子/能验证一个小实现”等可观察成果，不承诺“精通、上线生产、独立处理所有故障”。
- 页面涵盖生产能力不等于小时主线取得生产资格；预算不足时请用户选收窄成果或增加预算，不隐去验收。
- 页面描述本来含实战时优先保留合适的小练习；代码/材料没有访问到，就先用标明的教学假设，不说已取得配套项目或运行过讲师示例。

## 5. 输出顺序

依请求调整详略；不把所有内检字段都展示给用户。

### 仅链接 / 尚无预算

1. **课程读取范围**：介绍和相关展开项/大纲是否完整、正文是否未读、未发布状态。
2. **全貌**：课程解决什么、关键关系、一个例子与边界；图谱可读且实际渲染，沿用教练和用户偏好，不仅抛Mermaid源码。
3. **全课程路线草案**：原模块顺序、可观察阶段成果与后续去向，不擅自排时。
4. **下一步选择**：仅补必要目标/预算，不自动开课。

### 目标与预算已确认 / 只要计划

1. 课程与本轮目标、已确认预算、来源范围。
2. 原课模块到本轮/后续路线的映射。
3. 逐节标题、对应原讲、成果、依赖、主线/选学、分钟拆分。
4. 总预算与额外实践估时、未覆盖/未发布项、验收方式。
5. 等待用户明确开始；不讲第1节，不启动计时。

### 明确开始 / 继续

按教练已有路由执行，一个小节一轮。正文标进度、来源原讲及本节分钟；理解检查可选，反馈仅按本题。计时与进度状态沿用教练，不做新运行时。

## 6. 事实、来源与原创教学

- “课程页面写了什么”引用用户指定课程URL；读出的图片材料也保留该课程出处，不以临时检查截图代替来源。
- “我为什么这样分组/估时”标教练设计，不附来源使其像讲师安排。
- 介绍页只提供课的描述与范围。没有每讲正文时，不能说“第N讲原文结论是”；可以说“按第N讲题目安排的学习主题”。
- 实际授课用当前公开官方文档/原始论文/指定版本代码等核验，补充材料与原课材料分别标明。计划阶段不用为每个标题搜索整个领域。
- 不复刻付费正文、音频、视频或整套讲义；在允许范围内做摘要与原创讲解，不能冒称替代购买原课程。
- 原图默认作证据阅读，不复制进公共Skill仓库；公开仓库只放技能指令和必要验收材料，不放学习者私人记录、凭据或抓取整课。

## 7. 后续与状态

- 每门课分别保留目录版本、原始/实际URL、完整性、原讲到教练节映射、预算与目标、进度/验证状态。
- 继续时恢复原计划，未验证不等于未讲，跳过不等于完成。临时深挖答完回原节，不自动改预算。
- 新讲发布或大纲改版时重新读取受影响区域，明确差异后调整未学部分，保留已学状态；标题相同而课程不同不能合并。
- 没有持久化能力给可复制快照；用户要求文件再用宿主文件技能写入合适目录并交付。计时器本机状态只留本机，不跟随课程计划进入GitHub。
