# 学习计时：可见倒计时与课程联动

本资源只在需要真实倒计时的学习会话中加载。预计时长仍是学习量预算，不是掌握证明；截图中的生成耗时也不是用户学习耗时。

## 默认行为

- 用户已选择计时，或当前学习设置启用自动计时后，每次**实际交付一个小节**，按标题‘预计N分钟’自动启动。生成计划时不为所有未来小节启动计时。
- 默认L2/L3小节启用；L1只在用户要求计时或既有设置明确包含L1时启用。不改动层次进入许可。
- 先准备本节正文，再在交付前启动计时，避免资料搜索和生成耗时消耗预算。不能精确监听最后一个字呈现时刻，注明计时起点是启动工具成功时，而不是声称识别了用户开始阅读。
- 同一节补充解释、答题反馈、重新输出不得重置。下一节交付时换新节并替换该会话前节计时。跨会话不得替换另一会话计时器。
- 用户说暂停学习/休息：暂停计时；继续学习：恢复；重新计时：重置当前预算；结束/跳过：停止当前节。正文未准备好时不要启动下一节。
- 到零只提示‘本节预算已用完’，不强制跳课、不把它记为掌握、不自动结束业务工具或生成新题。

## 展示能力选择

1. 宿主已有真实的原生计时组件且有可用调用方式时优先使用；仅看到聊天正文或工具用时不能推断原生倒计时存在。
2. 豆包工作等支持右侧浏览器且能访问**本机**时，用本技能提供的本机页面。先列出现有侧栏标签，复用当前学习会话已有计时器；没有时创建浏览器页签，URL必须来自脚本返回，不能猜端口。
3. 有浏览器但不能运行本机脚本时，交付 `assets/学习倒计时.html`。首次打开自动开始默认13分钟，用户可调整；这是独立页面，不能声称已经与聊天同步。
4. 不能运行网页时说明无法实时展示，给可核验起止时间或让用户自选外部计时器。静态Markdown无法按秒刷新，不能伪造动态组件。

右侧计时器不覆盖正文，不把整个课程移入计时页。小节标题保留预算，聊天最多一行注明‘本节倒计时已在右侧开始’，不要逐秒发消息。

## 本机服务模式

需要Python 3.9+，只用标准库。代码位于 `scripts/learning_timer.py`，页面位于 `assets/学习倒计时.html`。这是可选本地辅助，不要求npm、插件、外部账号或API密钥。

- 启动前读取脚本并遵守宿主命令权限。确认状态目录父目录存在。
- `--state-dir` 使用当前学习会话的私有任务目录，**不要放进技能目录、Git仓库、跨会话共享目录或公共同步目录**。不写死作者路径，实际命令中代入本次的绝对路径。
- 一个会话只用一套状态目录，一次只从一个执行者发命令。服务仅绑定127.0.0.1和操作系统分配的空闲端口，不暴露局域网、不添加开机启动；最长运行8小时。
- 控制接口需要随机本地令牌，校验Host/Origin，无跨域许可。连接文件权限受限；不读取或输出令牌，不把运行状态、标题和令牌发布到GitHub。
- 命令返回URL与状态；如创建/更新结果未知先用status核验，不盲重发。报失败不得声称已开始。

命令示意（占位仅用于文档；执行时替换为真实路径）：

```bash
python3 <技能目录>/scripts/learning_timer.py start \
  --state-dir <本学习会话状态目录> \
  --minutes 13 \
  --title '主线 2/5：超时到底终止了什么' \
  --lesson-key '本主题:L2:2'
```

`lesson_key` 在当前会话内稳定区分主题、层次与小节；同键start幂等，不重置暂停、结束或已用完的节。需要重开同一节用reset，不生成随机新键绕过去。

其他命令都带同一 `--state-dir`：

- `ensure`：复用或启动服务，不启动新的学习预算。
- `status`：读真实状态与URL；不启动服务。
- `pause` / `resume`：暂停、恢复；重复调用不重复扣时。
- `reset`：当前节重新计时，不改课程进度。
- `stop`：停止当前预算，服务保留以便下一节。
- `shutdown`：结束服务，仅结束本会话的计时器，不杀其他进程。

## 时间实现与边界

- 服务和页面按持久截止时间减当前时间计算剩余，不靠每秒减一；HTTP状态给服务器时间和截止时间，页面按时间差显示，定期校准。这样后台节流与休眠不导致漏秒；代价是系统时钟被大幅手动调整会影响倒计时。
- 页面隐藏、浏览器后台节流后重新可见，按截止时间恢复；默认不自动暂停。电脑休眠会经过时间预算，醒来可能已经到零；用户休息应主动暂停。
- 进程重启时用持久截止时间恢复；不保证跨设备时间同步。
- 页面中的‘已计时’是本节预算计时段，不是用户实际阅读、专注或掌握程度，暂停时间不算入。
- 服务停止/8小时退出后，页面可按最后截止时间继续显示，但控制/跨节联动不可用；醒目报告断连，再用ensure恢复。不能声称关电脑仍会发送提醒。
- 到时默认只做页内视觉提示，无系统通知、飞书消息、音效或定时后台推送。若用户要这些另按宿主功能确认并实现。
- `http://127.0.0.1:...` 只在同一台本机有意义。云端、另一台电脑或手机不能访问，不把本机URL当公开分享链接。

## 独立页面模式

- HTML单文件可直接打开，无第三方库、无联网请求。首次加载默认13分钟并尝试localStorage保存；相同页面再次打开恢复已有状态，不无条件重置。
- 手动标题使用textContent，不把用户文字拼成HTML。时长必须大于0且不超过240分钟。
- 暂停、继续、重置和结束只控制页面计时；不会通知模型或触发下一节。打开两份不同文件可能产生独立计时，不声称跨标签实时同步。
- 模板13分钟用于独立演示。实际小节须由服务按当节预算配置，不能每节都错用13分钟。

## 验证与维护

运行 `scripts/test_learning_timer.py` 验证本地状态转换和时间口径。根据宿主开发规则做接口与页面验收，核验标题、分钟、按钮、断连提示与正确侧栏；报告实际完成的验证，不把单元测试当所有客户端实测。修改技能资源后保留原主题教学行为，不擅自将整套技能改成计时器应用。
